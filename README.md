# NRTimer
App qui sert à avoir le timer des tempêtes pour Elden ring Nightrein

L'app requiert pynput. 

```pip install pynput --user```

Trois boutons F1,F2 et F5. 

F1 à appuyer pour lancer le 1er jour. Le premier jour contient:
Jour 1 Phase 1
Tempête 1 
Jour 1 Phase 2
Tempête 2 
Boss 1  
--> Appuyer sur F1 dès que vous voyez "Jour 1" à l'écran.

F2 à appuyer pour lancer le 2eme jour. Le premier jour contient:
Jour 2 Phase 1
Tempête 1 
Jour 2 Phase 2
Tempête 2 
Boss 2
--> Appuyer sur F2 dès que vous voyez "Jour 2" à l'écran. 

F5 stoppe le chrono au global et un deuxième appuie reset les chronos.
